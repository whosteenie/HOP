## UGS migration test matrix (Lobby + Matchmaker + Relay, Steam social)

This file is a lightweight checklist for validating the Roadmap B migration while the **backend switch** exists.

### How to enable the UGS backend

Edit your settings JSON (generated by the game) and set:

- `network.useUgsBackend = true`

Then restart the game.

### Test cases

#### Auth bootstrap
- Launch with Steam online.
  - Expected: no Auth/Vivox errors; UGS initializes silently.
- Launch with Steam offline.
  - Expected: UGS signs in anonymously; Steam social features are unavailable; game remains stable.

#### UGS party lobby (private)
- Click Host.
  - Expected: party lobby is created; Steam rich presence `connect` string is set (joinable by friends).
- From a second account: Join Game via Steam friends list.
  - Expected: game receives rich presence join request and joins the UGS party lobby.

#### UGS private match
- As party host, choose a mode card for private match.
  - Expected: host creates Relay allocation + match lobby; party lobby publishes follow id; clients follow; NGO host starts and loads Game scene.

#### UGS public matchmaking (Matchmaker)
- Click Find Game / Quick Play.
  - Expected: ticket is created; UI shows searching; once matched, one client becomes host, creates Relay-backed match lobby indexed by `matchId`; others find it via query and join.
- Cancel matchmaking.
  - Expected: ticket polling stops; UI returns to menu state (no stuck “Searching”).

#### Steam overlay + invites
- Open overlay (Shift+Tab) and invite a friend while in party.
  - Expected: invite works; Join Game routes via rich presence connect string; no Steam lobby required.

### Known limitations during transition
- Party UI elements may still be Steam-lobby-driven until fully migrated to show UGS lobby membership.
